# EduConnect 🎓

**EduConnect** — это современная образовательная платформа, разработанная для эффективного взаимодействия между учениками и репетиторами. Проект объединяет в себе интуитивно понятный интерфейс и мощные инструменты для планирования обучения.

##  Основные возможности 

- **Умный поиск репетиторов:** Фильтрация по предметам, рейтингу и стоимости обучения.
- **Интерактивный дашборд:** Быстрый доступ к ближайшим занятиям и отслеживание прогресса обучения.
- **Управление расписанием:** Встроенный календарь для планирования и мониторинга уроков. 
- **Персонализированные профили:** Детальная информация о квалификации преподавателей и личные кабинеты студентов. 
- **Ролевая модель:** Поддержка различных сценариев использования для учеников и учителей.

## 🛠 Технологический стек 
 
### Frontend
- **React 19** & **TypeScript** — основа приложения.
- **Vite** — быстрая сборка и разработка.
- **Tailwind CSS 4** — современная стилизация.
- **Framer Motion** — плавная и живая анимация интерфейса.
- **Lucide React** — набор качественных иконок.

### Backend / Logic
- **C# (.NET)** — демонстрационная реализация бизнес-логики и моделей данных (файлы `EduConnect.cs`).

## 💻 Запуск проекта

### Предварительные требования
- Node.js (версия 18 или выше)
- npm или yarn

### Локальная разработка

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <repository-url>
    cd educonnect
    ```

2.  **Установите зависимости:**
    ```bash
    npm install
    ```

3.  **Настройте переменные окружения:**
    Создайте файл `.env.local` и добавьте ваш ключ API (если требуется функционал ИИ):
    ```env
    GEMINI_API_KEY=your_api_key_here
    ```

4.  **Запустите сервер для разработки:**
    ```bash
    npm run dev
    ```
    Приложение будет доступно по адресу `http://localhost:3000`.
